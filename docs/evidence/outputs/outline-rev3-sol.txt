## 2. 问题、定位与预期价值

### 2.1 问题陈述

- 聚合方处理同一包版本的许可证、发布时间、仓库链接、制品摘要及生命周期信息时，需要区分字段错误、同步延迟、语义差异和证据不足。
- 字符串差异不能解释来源依赖、字段适用范围、制品身份或观察时间。
- 来源一致可能只是摄取传播一致；字段不同也可能来自不同分析范围。
- PMV 将差异转换为有理由、有证据引用、可复算的质检结果，供聚合方决定重查、复核或修订。

### 2.2 组件定位

- 消费注册表 API、聚合方记录及固定快照。
- 提供 CLI、Python 库、版本化规则和 JSON Schema。
- 输出字段级判定、来源依赖、观察时间及最小证据包。
- 拟接入 **CodeSupply 数据摄取后、聚合记录发布前** 的质量检查步骤；另提供既有数据集批量审查入口。
- 接入接口通过 AboutCode issue 对齐，交付适配示例；当前不宣称已经接入或获得采用。

### 2.3 三项增量能力

1. **跨源判定**：记录原始值、归一值、字段范围、来源依赖、判定规则及理由。
2. **时间追踪**：区分发布时间、抓取时间、索引时间及首次观察时间；记录差异持续与后续出现。
3. **离线复现**：固定输入、规则、代码版本、依赖和参数，复算基线结果。

PURL 解析复用现有标准；本轮不承担漏洞归一、完整依赖图或通用供应链平台建设。

## 4. 双生态来源与依赖关系

| 生态 | 最低来源组合 | 补充来源 |
|---|---|---|
| npm | npm registry＋deps.dev | ClearlyDefined 许可证分析 |
| PyPI | PyPI＋deps.dev | ClearlyDefined 许可证分析 |

- PyPI JSON 与 Simple 属于同一注册表的不同接口，不计为两个独立真值来源。
- deps.dev 衍生自注册表的字段记录依赖关系；一致只能证明相关范围内的传播一致。
- ClearlyDefined 记录制品坐标、declared／discovered 字段、facet、扫描工具及修订来源；无法取得的信息标为未知。
- 来源依赖尽量落实到字段层。
- OSV `withdrawn` 表示漏洞记录撤回，不用于判断包撤回。
- 网络失败、缺字段与不可比条件保留在输出中，不补造证据。

### 5.5 四类真实案例提交门槛

- **真实错误**：至少一个有字段定义、同范围比较和原始材料支持的具体字段错误。
- **同步延迟**：至少一个发布时间／可用时间、缺失观察、后续出现观察均可追溯的案例。
- **语义差异**：保留 esprima 字段与 core facet 证据；不将当前摘要快照夸大为已核验完整仓库逐文件扫描。

## 6. 判定规则与输出契约

### 6.1 类别与含义

以当前结果 JSON 的大写类别为统一口径：

| 类别 | 判定范围 |
|---|---|
| `REAL_ERROR` | 有证据证明同一范围内的具体字段错误；错误事实与原因归责分开 |
| `SYNC_DELAY` | 有可信时间链支持可见性延迟，并保留观察区间 |
| `SEMANTIC_DIVERGENCE` | 字段含义、分析范围或表达式不同，不自动采信一方 |
| `INDETERMINATE`／`undecidable` | 缺证、时间链不足、跨制品、跨算法或其他不可比条件 |
| `DIGEST_CONFLICT` | 同制品、同算法且正确归一后摘要不同；结论限于摘要冲突 |
| `CONSISTENT` | 仅指已检查范围内一致，不代表全包正确 |

### 6.2 与修复后 verifier.py 对应的约束

- **时间缺失**：在注册表可用、deps.dev 404 的延迟判断分支，发布时间缺失或时间差无效时返回 `undecidable`。
- **观察链不足**：只有一次 404、没有后续观察时返回 `undecidable`，可附疑似延迟说明。
- **空证据**：可用源少于两个，或可用源的实质元数据全部为空时返回 `undecidable`。
- **制品同一性**：匹配文件名之外，两边必须具备制品级证据；当前实现检查摘要、URL 或清单等证据是否存在。该检查是必要门槛，不能宣称已经完整证明两个构建内容同一。
- **摘要算法**：只比较共享算法；无共享算法返回 `undecidable`。
- **摘要归一化**：当前实现执行首尾空白与大小写归一，并在 `DIGEST_03_NORMALIZATION` 记录原始值和归一值。这一口径限于十六进制摘要；base64 必须按编码处理，不能直接小写化。
- **责任归属**：当前真实错误分支不再输出解析器故障归责；其分类器／标准许可证启发式仍须经字段语义核验后用于事实主张。
- **语义差异**：保留 AND／OR 结构、来源字段和分析范围。
- **来源依赖**：衍生源一致不计为独立真值证明。
- **synthetic**：构造比较输入与输出标记一致。

提交前对后续观察的成功状态、时间顺序、摘要编码和制品身份依据继续复核；不以现有 14 项测试宣称所有边界均已覆盖。

### 6.3 输入输出

- **输入**：带版本 PURL、来源配置、固定快照、规则版本及可选制品比较对。
- **输出**：原始值、归一值、类别、原因码、字段／制品范围、证据引用、来源依赖、时间信息及审计轨。
- 区分 `fetched_at`、`published_at`、`indexed_at`、`first_seen_at`；不可获得则记录缺失。
- 原型 confidence 为未校准规则数值，不作为正确率或概率宣传。
- 聚合方依据策略处理：疑似延迟重查、语义差异复核、不可判定补证、真实错误或摘要冲突进入审查。

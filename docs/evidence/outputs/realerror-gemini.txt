   - `git ls-remote https://github.com/sponsors/ofek` 直接返回 `fatal: repository not found`（exit code 128），证明该链接**物理上不是 Git 仓库**，无法检出代码；

2. **规范依据**:
   - PEP 566 (Metadata 2.1) 与 PEP 753 明确定义了 `Project-URL: label, url` 的标签映射关系，`Source` 与 `Funding` 互斥。
3. **权威维护者归因确认**:
   - Google [deps.dev Issue #220](https://github.com/google/deps.dev/issues/220) 官方团队成员公开确认系解析器在处理 PEP 753 规范标签时的提取缺陷；hatch-vcs 作者也亲自证实了该问题。
